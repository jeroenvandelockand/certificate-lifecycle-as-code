# ADR 002: Private keys are not stored in Git

Status: Accepted

The lab CA key is generated at runtime and written directly to a Kubernetes
Secret. Workload private keys are generated by cert-manager and also live only
in Kubernetes Secrets.

The host-side CA files are kept in `.clac/runtime/<cluster-name>`. The entire
`.clac/` directory is ignored by Git and excluded when the local Git snapshot
is constructed.

Production implementations must replace the lab CA with protected enterprise
PKI and define backup, rotation, revocation and recovery controls.
